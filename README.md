# 💣 Minesweeper

A feature-rich Minesweeper game developed in **Unity using C#**, featuring classic Minesweeper mechanics alongside custom game modes and gameplay systems.

The project was built to explore game development, object-oriented programming, procedural generation, and algorithmic problem solving.

> **Note:** This repository contains an earlier public version of the source code.  
> The project is currently under active development with additional game modes, improved visuals, and new gameplay features.

---

## 🎮 Features

- Classic Minesweeper gameplay
- First-click-safe mine generation
- Recursive flood-fill cell revealing
- Flagging system
- Chording
- Timer and remaining mine counter
- Multiple difficulty levels
- No-guess board generation
- Custom game modes

---

## 🕹️ Game Modes

### Classic Mode
Traditional Minesweeper gameplay with multiple difficulty levels.

### Infinite Mode
An alternative game mode designed around an expanding/infinite Minesweeper board.

### 2x2 Mode
A custom mode introducing 2x2 cells and modified board mechanics.

## 🎯 Controls

| Input | Action |
|---|---|
| Left Click | Reveal cell |
| Right Click | Place/remove flag |
| Left Click on revealed number | Chord |
