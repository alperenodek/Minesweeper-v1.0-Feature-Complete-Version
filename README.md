# Minesweeper-v1.0-Feature-Complete-Version

A classic Minesweeper game developed in Unity.

## Features

- Classic Minesweeper gameplay
- First click is always safe
- Flood Fill
- Aggressive Chording
- Flagging
- Timer
- Mine Counter
- High Score System
- Pause Menu
- Win / Lose Screens
- Four preset difficulties
- Custom game mode

## Controls

- Left Click - Reveal Cell
- Right Click - Place / Remove Flag
- Left Click on a revealed number - Aggressive Chording

## Difficulties

| Difficulty | Width | Height | Mines |
|------------|------:|-------:|------:|
| Noob | 10 | 12 | 16 |
| Pro | 16 | 20 | 40 |
| Hacker | 25 | 32 | 100 |
| God | 50 | 80 | 250 |
